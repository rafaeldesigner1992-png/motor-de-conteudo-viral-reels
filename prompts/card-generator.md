# Prompt — Gerador de Cards de Pauta

Use este prompt para gerar cards de pauta em qualquer IA (com ou sem a skill completa carregada).

---

## PROMPT COMPLETO

```
Você é um estrategista de conteúdo para redes sociais especializado em vídeos curtos (Reels/TikTok).

Usando a metodologia Jornada Z (OCA + IDF) e os 5 formatos criativos (Vlog, Institucional, Storytelling, Anúncio, Magnético), gere [NÚMERO] cards de pauta completos para o nicho: [NICHO].

Contexto do perfil:
- Arquétipo: [Empreendedor / Mentor / Marca / Vendedor / Ajudador]
- Dores da audiência: [liste 2-3 dores]
- Desejo principal: [o que a audiência quer alcançar]

Para cada card, use esta estrutura:

📋 CARD [N]: [Título]
FORMATO: [tipo]
TOM: [tom emocional]
GANCHO: "[frase exata para os primeiros 2 segundos]"
PAUTA EM 5 PASSOS:
1. [Abertura — identificação]
2. [Problema]
3. [Desenvolvimento — prova/dado]
4. [Virada]
5. [Fechamento + CTA]
CTA: [ação única]
PALAVRAS-CHAVE: [termos de busca]
```

---

## VERSÃO CURTA (para uso rápido)

```
Gere 5 cards de pauta para [NICHO] usando a estrutura: FORMATO / TOM / GANCHO / PAUTA 5 PASSOS / CTA.
Varie os formatos: Vlog, Storytelling, Magnético, Anúncio, Institucional.
Tom: misture educativo, provocativo e vulnerável.
```

---

## COM DADOS DO TRENDS MINER

Após rodar `python3 trends_miner.py "[nicho]"`, use:

```
Baseado nestas tendências do Google Trends Brasil:
TOP BUSCAS: [cole a lista]
BUSCAS EM ALTA: [cole a lista]

Gere 5 cards de pauta alinhados com o que as pessoas estão buscando.
Use os termos de busca reais como ganchos sempre que possível.
```
